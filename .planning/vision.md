# Vision - BellePoule Modern

## Mission

Créer l'application open-source de référence pour la gestion de compétitions d'escrime, avec une spécialisation sur les règles **FFE Sabre Laser**.

## Problème résolu

Les logiciels existants de gestion de compétitions d'escrime sont :
- Propriétaires et coûteux
- Non adaptés aux règles spécifiques du Sabre Laser
- Difficiles à utiliser sur tablette
- Dépendants d'une connexion internet

## Solution

BellePoule Modern offre :
- **Open Source** : Gratuit, GPL-3.0, contributions bienvenues
- **Sabre Laser natif** : Zones A/B/C, cartons FFE, Quest, mort subite
- **Mobile-first** : PWA optimisée tablette, mode hors-ligne
- **Temps réel** : Dashboard spectateurs, sync multi-appareils

## Utilisateurs cibles

1. **Arbitres** : Saisie rapide des scores sur tablette
2. **Organisateurs** : Gestion complète de la compétition
3. **Spectateurs** : Suivi en direct des résultats
4. **Clubs** : Export FFE pour les classements

## Valeurs

- **Simplicité** : Une fonctionnalité = un clic
- **Fiabilité** : Tests unitaires complets, pas de perte de données
- **Performance** : Réponse < 100ms, fonctionne hors-ligne
- **Accessibilité** : Interface claire, gros boutons tactiles

## Métriques de succès

- Adoption par 10+ clubs FFE
- Score Lighthouse > 90
- Couverture tests > 80%
- 0 bug critique en compétition
